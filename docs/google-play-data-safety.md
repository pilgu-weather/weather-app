# Weather Fit Google Play 데이터 보안 체크리스트

현재 코드 기준 점검 자료다. Play Console 제출 전 실제 운영 설정과 서비스 제공자 계약을 함께 확인한다.

## 위치

- 데이터 유형: 정확한 위치 및 대략적인 위치
- 수집 여부: 예. 사용자가 현재 위치 권한을 허용할 때 위도와 경도가 기기 밖으로 전송된다.
- 필수 여부: 선택 사항. 거부하면 기본 지역 날씨를 이용한다.
- 목적: 앱 기능 제공
- 처리 대상: Weather Fit(Render 호스팅)과 OpenWeather
- 전송 암호화: 예. HTTPS 사용
- 공유 여부: Render와 OpenWeather가 개발자를 대신해 처리하는 서비스 제공자 예외에 해당하는지 계약 조건을 확인한 뒤 Play Console에서 최종 판단한다.

## 추천 평가 및 코디 신고

- 데이터 유형 후보: 기타 사용자 생성 콘텐츠 또는 앱 활동
- 수집 여부: 사용자가 평가나 신고를 제출할 때만 수집
- 목적: 앱 기능 제공, 추천 품질 개선, 신고 처리
- 포함 정보: 평가·신고 내용, 지역명, 날씨와 기온, 코디 정보, 좌표가 제거된 페이지 주소, User-Agent
- 외부 처리: 운영 알림을 위해 Discord로 일부 정보가 전송될 수 있음
- 정확한 좌표 저장: 하지 않음. 클라이언트와 서버에서 `lat`, `lon`을 페이지 주소에서 제거함

## Play Console 확인 사항

- 정확한 위치와 대략적인 위치를 모두 `수집함`으로 표시
- 위치 수집을 `선택 사항` 및 `앱 기능` 목적으로 표시
- 추천 평가·신고 데이터 유형과 목적 표시
- 모든 수집 데이터가 전송 중 암호화되는지 확인
- 개인정보처리방침 URL을 `https://weather-app-1-xy3b.onrender.com/privacy`로 등록
- 데이터 삭제 요청 방법으로 `northstarlabshelp@gmail.com` 안내
- Render, OpenWeather, Discord의 서비스 제공자 해당 여부와 국외 처리 내용을 최종 검토

Google Play은 정확한 위치를 3제곱킬로미터보다 좁은 범위의 물리적 위치로 정의하며, `ACCESS_FINE_LOCATION`으로 얻는 위치를 예로 든다. 최종 제출 내용은 실제 배포 앱과 항상 일치해야 한다.
